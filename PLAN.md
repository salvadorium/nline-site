# План

1. **Первая версия `index.html`** — собрать страницу по спецификации, встроить стили и простой JavaScript, реализовать выбор программы с начальными данными «Луны».
2. **Визуальная итерация** — после проверки в браузере уточнить визуальное направление: цвета, типографику, композицию и заметность карточки.
3. **Интерактивная итерация** — отдельно добавить сброс выбора и возврат к исходному состоянию «Луна».
4. **Финальная сверка** — проверить соответствие README, спецификации и границам; вручную пройти пользовательский сценарий в браузере, включая сброс.
