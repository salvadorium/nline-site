# Спецификация

## Цель

Одностраничный сайт «Ночная линия» сохраняет светлый космический дизайн существующего index.html. Сайт объясняет формат вечера, показывает фиксированное меню и позволяет выбрать позицию с локальным подтверждением.

## Структура и визуальное направление

- Существующий index.html остаётся интерфейсом сайта и отдаётся сервером для GET / и GET /index.html.
- Сохраняются шапка, первый экран с иллюстрацией Луны, карточка формата вечера и блок шагов.
- Блок программ используется для трёх карточек меню: «Коричная капибара», «Ванильный круассан», «Шоколадный круассан».
- Светлая гамма, звёздный фон, лунная иллюстрация, типографика и адаптивная вёрстка остаются частью дизайна.
- Выбор визуально выделяет одну карточку, показывает локальное подтверждение и кнопку сброса. «Проверить заказ» показывает доступность и время сервера.

## API

| Метод и путь | Поведение |
|---|---|
| GET /api/menu | Возвращает JSON с тремя фиксированными позициями и их идентификаторами. |
| POST /api/selection | Принимает JSON { "id": "..." }, проверяет идентификатор, возвращает локальное подтверждение. Неизвестная позиция отклоняется. |
| POST /api/reset | Возвращает сообщение о сбросе выбора. |
| GET /api/status | Возвращает { "ok": true, "time": "..." } с текущим серверным временем. |

Остальные методы и пути отвечают HTTP 404. Страница клиента загружает меню через API и использует указанные маршруты для действий.

## Ограничения проекта

- Сохранить структуру: AGENTS.md, README.md, PLAN.md, spec.md, index.html, package.json, server.js; добавить amvera.yaml в корень.
- AGENTS.md не изменять. Существующий index.html не удалять и не заменять отдельной страницей.
- Сервер использует только встроенные node:http, node:fs, node:path, слушает 0.0.0.0, берёт порт из process.env.PORT или использует 3000 локально.
- package.json имеет поле "private": true, scripts start: node server.js и build: node --check server.js; сторонних dependencies/devDependencies нет.
- amvera.yaml: Node.js, npm 18, сборка npm run build, запуск npm run start, containerPort: 3000.
- Не добавлять внешние зависимости, базы данных, Docker, Volume, Variables, CLI-команды Amvera, отдельные статические папки, оплату, реальный заказ, авторизацию, клиентское хранилище или внешние запросы.
- Выбор существует только в памяти интерфейса и не сохраняется сервером, в файлах, SQLite или браузере.
