# «Ночная линия»

Одностраничный сайт ночной обсерватории со светлой звёздной темой и локальным выбором угощения из меню. Node.js-сервер раздаёт существующий `index.html` и предоставляет API без базы данных и внешних пакетов.

## Запуск локально

Нужен Node.js 18 или новее. В корне проекта выполните:

```sh
npm run build
npm start
```

Откройте <http://localhost:3000>. `npm run build` проверяет синтаксис `server.js`; установка сторонних зависимостей не требуется.

## API

- `GET /api/menu` — фиксированное меню.
- `POST /api/selection` — проверяет идентификатор позиции и возвращает локальное подтверждение.
- `POST /api/reset` — подтверждает сброс интерфейсного выбора.
- `GET /api/status` — сообщает состояние сервера и текущее время.

Выбор не сохраняется между запросами или перезагрузками. Оплаты и настоящего оформления заказа нет.

## Деплой на Amvera

В корне находится `amvera.yaml`: окружение Node.js, toolchain npm 18, сборка `npm run build`, запуск `npm run start` и порт контейнера 3000. Создайте Node.js-проект Amvera из этого репозитория и выполните деплой штатным способом через интерфейс Amvera. Сервер привязывается к `0.0.0.0` и использует порт из `PORT`, если платформа его задаёт.

## Структура

- `index.html` — интерфейс, стили и клиентские запросы к API.
- `server.js` — HTTP-сервер на встроенных модулях Node.js.
- `package.json` — команды запуска и проверки без зависимостей.
- `amvera.yaml` — конфигурация сборки и запуска на Amvera.
- `spec.md` и `PLAN.md` — спецификация и план ручной проверки.
