# «Ночная линия»

Компактное описание одностраничного сайта студии городских астрономических наблюдений. Сайт знакомит с форматом мероприятия и помогает выбрать одну из трёх программ: «Луна», «Планеты» или «Созвездия».

## Локальное открытие

Готовый сайт — один самодостаточный файл `index.html` со встроенными HTML, CSS и простым JavaScript. Он работает при прямом локальном открытии в современном браузере: дважды щёлкните файл или перетащите его в окно браузера. Сервер и подключение к интернету не нужны.

## Состав

Шапка со ссылками-якорями, первый экран с кнопкой перехода к выбору, заметная карточка формата вечера, интерактивный блок программ и три коротких шага о формате визита. Точные тексты и наблюдаемое поведение заданы в [spec.md](./spec.md); этапы реализации — в [PLAN.md](./PLAN.md).

## Границы

Только один `index.html` со встроенными HTML, CSS и простым JavaScript. Без фреймворков, пакетного менеджера, бэкенда и внешней базы данных; без внешних шрифтов, изображений, скриптов, таблиц стилей, зависимостей и сетевых запросов. Не добавлять формы отправки, реальное бронирование, внешние аккаунты, реальные персональные данные, секреты или публикацию. Не расширять функции за пределы согласованного сценария.
